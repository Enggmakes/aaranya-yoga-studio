# Aaranya Yoga Studio

Create a complete responsive website called Aaranya Yoga Studio, using the yoga website reference image attached in this conversation as the primary design direction. Premium peaceful editorial wellness aesthetic: warm ivory/cream backgrounds, forest botanical green accents, earthy beige and muted olive, elegant serif headlines, clean sans-serif body text, large natural yoga photography, generous whitespace, restrained botanical details. Avoid generic SaaS layouts, excessive gradients, glassmorphism and clutter.

Implement these pages with shared navigation and footer:
- Home: hero headline “Find Your Inner Peace”, supporting copy about slowing down and reconnecting, Explore Our Classes and Watch Video CTAs, Why Choose Aaranya benefits (Better Health, Stress Relief, Inner Balance, More Energy), popular programs, full-width “Ready to Begin Your Journey?” CTA, testimonial preview.
- About: story, philosophy, teaching approach, instructor profiles clearly marked as editable placeholders, editable illustrative stats.
- Programs: Hatha Yoga, Ashtanga Yoga, Meditation, Pranayama, Beginner Classes, Personalized Sessions. Each has imagery, concise copy, benefits and a working learn-more action.
- Schedule: weekly timetable with day, class, time, duration, mode and price; working category filters; editable demo class/package data; booking CTA.
- Testimonials: elegant responsive carousel/cards. Clearly label sample testimonials as demo content, not verified reviews.
- Contact: validated enquiry form with success/error feedback; use editable placeholders for phone, email and address; do not invent real contact details. WhatsApp action only works once a real number is configured; map placeholder until real address supplied.

Functional requirements: responsive desktop/tablet/mobile, accessible semantic HTML and keyboard focus, working route navigation, mobile menu, working filters and carousel controls, booking CTA opens an enquiry/booking flow, smooth scrolling, tasteful hover/motion with reduced-motion support, no dead buttons or placeholder links. SEO-friendly page metadata. Use React, TypeScript, Tailwind, reusable components and Lucide icons on the default Lovable stack. Keep copy warm, natural, authentic, calm and premium but approachable; avoid exaggerated health claims and invented credentials.

Build priority: make the homepage visually excellent and closely match the supplied reference, then complete all other pages to the same quality. Verify routes, interactions and responsive layouts.
